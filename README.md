# 🐍 PYTHON

Repositório de apoio às disciplinas introdutórias e intermediárias de programação utilizando a linguagem Python.

O material foi desenvolvido para auxiliar estudantes que estão iniciando seus estudos em programação, lógica computacional e desenvolvimento de soluções utilizando uma das linguagens mais populares da atualidade.

As aulas apresentam uma evolução gradual dos conceitos fundamentais da linguagem, iniciando com instalação e sintaxe básica, passando por estruturas de dados, controle de fluxo, funções, manipulação de arquivos, tratamento de exceções, programação gráfica, banco de dados, geração de gráficos e aplicações práticas.

Além dos exemplos didáticos, o repositório contém projetos completos de CRUD, manipulação de arquivos, automação de tarefas, análise de dados, geração de gráficos estatísticos e aplicações de matemática utilizando Python.

---

## 🎯 Objetivos

- Aprender lógica de programação utilizando Python;
- Compreender os principais tipos de dados da linguagem;
- Utilizar estruturas condicionais e de repetição;
- Desenvolver funções reutilizáveis;
- Trabalhar com listas, tuplas, dicionários e conjuntos;
- Manipular arquivos de diversos formatos;
- Tratar erros e exceções;
- Utilizar banco de dados em aplicações Python;
- Produzir visualizações de dados;
- Desenvolver aplicações com interface gráfica;
- Introduzir conceitos de documentação e boas práticas;
- Aplicar Python em problemas matemáticos e científicos.
